Privacy Policy

Last updated: 17 October 2026

1. Who uses this tool

Video Autopilot is a personal tool used only by its operator, Muhammad Aamir, to upload his own videos to his own accounts. It has no other users.

2. What data is accessed

When the operator authorizes the tool on a platform (for example TikTok or YouTube), the tool receives:

  • basic profile information of the operator's own account (such as display name), and
  • an access token that allows it to upload videos to that account.

The tool does not access followers, messages, contacts, or any other person's data.

3. How data is stored

Access tokens are stored only on the operator's own computer. They are not sold, shared with third parties, or sent anywhere except to the platform that issued them.

4. Data deletion

Access can be revoked at any time from the platform's account settings (for example TikTok: Settings and privacy → Security → Manage app permissions). Deleting the local token file removes all stored data.

5. Website analytics

This website uses Google Analytics to understand how visitors use it (for example, which pages are viewed). Google may set cookies for this purpose. No personal information is sold. You can opt out with the Google Analytics opt-out browser add-on.
