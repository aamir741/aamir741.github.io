Chapter 16 MCQs: IT General Controls for Managing Risk

Chapter 16 covers IT General Controls: what ITGCs are, their objectives, their importance in risk management, the key components such as access, change management, operations and physical security, implementation and challenges.

Sample questions from Chapter 16

1. An IT auditor at a manufacturing company finds that a programmer can write changes to the financial reporting code and also approve those same changes for release to the live system. Which ITGC component is MOST directly weakened?

  1. Change Management Controls
  2. Physical Security Controls
  3. IT Operations Controls
  4. Backup and Recovery Controls
Show answer

A. Change Management Controls Every change must pass a formal approval process so that it is properly authorised; a programmer approving their own change defeats that, which is a Change Management weakness. IT Operations Controls cover backups, incidents and monitoring, not authorising changes.

2. A bank has excellent application controls within its loan system — validating credit limits and requiring dual approval for large loans. However, an unauthorised individual obtains database administrator access due to weak ITGCs and directly modifies loan records in the database, bypassing the application entirely. What does this scenario illustrate?

  1. Application controls are sufficient on their own, whatever the ITGCs
  2. ITGCs and application controls address identical and interchangeable risks
  3. The incident is a failure of physical security controls only
  4. Weak ITGCs can let users bypass even well-designed application controls
Show answer

D. Weak ITGCs can let users bypass even well-designed application controls ITGCs secure the environment in which application controls run; if ITGCs such as privileged access fail, application controls can be bypassed entirely, showing that ITGCs are the foundation.

3. The IT helpdesk at Faisal Spinning Mills logs every system outage, assigns a priority and tracks it through to resolution. This process forms part of which ITGC component?

  1. Change management controls
  2. Program development controls
  3. IT operations controls
  4. Access controls
Show answer

C. IT operations controls Incident management, together with backup and recovery and system monitoring, is part of IT operations controls. Change management governs modifications to systems, not handling of outages.
